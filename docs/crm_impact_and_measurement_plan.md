## 4. 해석

1. **금액 규모가 작다.** 대상이 연 3,787명이고 기준 재구매율이 1.77%라, 효과가 있어도 연 순이익은 수백~수천 헤알 수준이다. 이 메시지 하나로 매출을 바꾸는 사업이 아니라, 저비용으로 재구매 레버를 검증하는 실험이다.
2. **채널은 이메일이어야 한다.** 이메일은 7~14% 효과면 손익분기를 넘지만, SMS는 42~85%가 필요해 현실성이 낮다.
3. **검출 한계가 손익분기보다 훨씬 높다.** 현재 표본(그룹당 2,333명)으로는 +70.9% 이상만 검출된다. 이익이 나는 +10~30% 효과는 실험으로 확인할 수 없다. +30% 검출에는 그룹당 11,114명(총 22,228명)이 필요하고, 연 3,787명 속도로는 약 6년이 걸린다.
4. **따라서 다음 결정이 필요하다:** (a) 대상을 Q3·Q4 전체로 넓혀 표본을 늘리거나(모델 농축 효과는 줄어듦), (b) 여러 메시지 실험을 같은 측정 틀로 누적하거나, (c) 큰 효과만 확인하는 파일럿임을 인정하고 '효과 없음'으로 결론 내리지 않는다.

## 5. 측정 계획

| 항목 | 정의 |
|---|---|
| 핵심 지표 | 배정 고객 기준(ITT) 24시간 초과~30일 배송 완료 재구매율, 처치군 − 대조군 차이와 95% 신뢰구간 |
| 보조 지표 | 재구매 주문 금액, 같은 카테고리 재구매 비율, 메시지 열람·클릭률(선행 지표) |
| 보호 지표 | 수신거부율, 고객 불만 건수, 발송 비용 대비 공헌이익 |
| 배정 점검 | 그룹 비율 1:1 검정(SRM, p<0.01이면 결과 무효), 층별(금액 구간·지역·카테고리) 균형 |
| 기간 | 배정 후 30일 관찰 + 배송 완료 확인 기간 |
| 분석 | 사전 등록한 단일 검정(양측 α=0.05), 중간 확인으로 조기 종료하지 않음 |
| 판정 | ① 배정 정상 ② 효과 신뢰구간 하한 > 0 ③ 순이익 > 0 ④ 보호 지표 한도 이내를 모두 통과하면 확대. 표본 부족으로 유의하지 않으면 '효과 없음'이 아니라 '판단 보류' |
