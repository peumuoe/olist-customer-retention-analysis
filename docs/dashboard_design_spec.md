# Olist 고객 재구매 의사결정 대시보드 설계서

기준일: 2026-08-07  
상태: 도구 중립 설계 완료, 구현 도구 미선정

## 1. 사용자와 의사결정 목적

### Primary user

Olist의 CRM·고객경험·리텐션 책임자와 제한된 예산의 우선순위를 승인하는 사업 의사결정자다.

### 핵심 의사결정

1. 재구매 수준이 어느 정도이며 어느 기간에서 문제가 드러나는가?
2. 외부 관찰값과의 격차를 어떤 제한 아래 참고해야 하는가?
3. 어떤 고객 경험·고객군을 먼저 탐색해야 하는가?
4. 예측모델로 발송 후보를 얼마나 압축할 수 있으며 무엇을 놓치는가?
5. 지금 캠페인을 실행할 수 있는가, 아니면 어떤 조건을 먼저 갖춰야 하는가?

### 대시보드가 하지 않는 일

- 고객별 구매 여부를 확정하지 않는다.
- 외부 플랫폼 차이를 Olist 정책의 인과효과로 설명하지 않는다.
- 과거 재구매자를 캠페인 증분 구매자로 표현하지 않는다.
- 첫 주문 결제금액을 미래 CLV로 표현하지 않는다.
- 실제 연락 가능한 고객 목록을 제공하지 않는다.

## 2. 전체 정보 구조

```text

        ↓

        ↓

```

첫 페이지는 결론, 둘째와 셋째 페이지는 진단 근거, 넷째 페이지는 실행 가능성과 검증 조건을 담당한다.

## 3. 공통 표현 규칙

- 비율은 소수점 둘째 자리까지 `%`, 작은 차이는 `%p`로 표시한다.
- 분모가 다른 공식 KPI와 운영 ML 타깃은 같은 선으로 연결하지 않는다.
- 관찰값은 `Observed`, 실험으로만 확인할 값은 `Incremental/Not measured`로 구분한다.
- 외부 비교와 CRM 수용량에는 해석 제한 문구를 항상 표시한다.
- 적색은 성과 저하가 아니라 `차단/STOP`, 황색은 `보류/ITERATE`, 녹색은 `충족/GO`에만 사용한다.
- 필터로 인한 작은 표본은 고객 수와 양성 수를 함께 노출한다.

## 4. Page 01 — Executive Decision

### 목적

경영진이 30초 안에 현재 재구매 수준, 모델 활용 범위, 실행 결론과 다음 행동을 이해하게 한다.

### 배치

```text
┌──────────────────────────────────────────────────────────┐
│ 제목 · 기준일 · 현재 결정: DO_NOT_LAUNCH                │
├──────────┬──────────┬──────────┬──────────┬─────────────┤
│ 30일 KPI │ 365일 KPI│ Lift@10% │ Recall@10%│ 역사 후보 수│
├───────────────────────────────┬──────────────────────────┤
│ 누적 재구매율 30~365일        │ Launch Gate 상태         │
├───────────────────────────────┼──────────────────────────┤
│ Action Item 우선순위          │ 핵심 제한·다음 단계      │
└───────────────────────────────┴──────────────────────────┘
```

### KPI

| KPI | 값 | 데이터 |
|---|---:|---|
| 공식 30일 재구매율 | 1.5823% | `fact_retention` |
| 공식 365일 재구매율 | 4.5331% | `fact_retention` |
| 테스트 Lift@10% | 1.7588 | `fact_model_performance` |
| 테스트 Recall@10% | 17.59% | `fact_model_performance` |
| 역사적 Q3·Q4 후보 | 4,667명 | `fact_crm_capacity` |
| 현재 실행 결정 | DO_NOT_LAUNCH | `fact_launch_gate` |

### 상호작용

- 기준 KPI 정의 선택: 공식 KPI / 운영 ML 타깃
- Action Item 선택 시 근거·위험·필요 데이터 표시
- Launch Gate 선택 시 차단 이유와 해소 조건 표시

## 5. Page 02 — Retention & Benchmark

### 목적

관찰기간에 따른 Olist 누적 재구매율과 외부 플랫폼의 관찰값을 정의 차이와 함께 진단한다.

### 배치

```text
┌──────────────────────────────────────────────────────────┐
│ KPI 정의 선택 · 관찰기간 선택                           │
├───────────────────────────────┬──────────────────────────┤
│ Olist 누적 재구매율 선그래프  │ 플랫폼별 기간 비교       │
├───────────────────────────────┼──────────────────────────┤
│ 적격 고객·재구매자 분모 표    │ 정의·사업구조 제한 카드  │
└───────────────────────────────┴──────────────────────────┘
```

### 핵심 시각화

- Olist 30·60·90·180·365일 누적 재구매율 선그래프
- 플랫폼 × 관찰기간 점그래프 또는 그룹 막대
- 적격 고객 수와 재구매 고객 수를 함께 보여주는 상세표

### 필수 주석

외부 차이는 구매 이벤트·상품 구성·채널·관찰기간·사업모델 차이를 포함하며 Olist 정책의 인과적 열위를 의미하지 않는다.

## 6. Page 03 — Opportunity Segments

### 목적

고객 규모·재구매율 격차·관찰 고객가치·개입 가능성을 함께 보고 탐색 우선순위를 정한다.

### 배치

```text
┌──────────────────────────────────────────────────────────┐
│ 차원 선택: 카테고리 / 가치구간 / 배송경험              │
├───────────────────────────────┬──────────────────────────┤
│ 고객 규모 × 재구매율 산점도  │ 우선순위 Top N           │
├───────────────────────────────┼──────────────────────────┤
│ 우선순위 구성요소 분해        │ 선택 고객군 상세·주의    │
└───────────────────────────────┴──────────────────────────┘
```

### 핵심 시각화

- x축 고객 수, y축 30일 재구매율, 크기 관찰 주문가치, 색상 개입 가능성의 버블 차트
- 균형점수 순위 막대와 고객군별 구성요소 툴팁
- 고객군 선택 시 고객 수·재구매자 수·전체 대비 격차·첫 주문 결제금액 표시

### 해석 제한

우선순위 점수는 전문가 판단 루브릭이며 캠페인 반응확률 또는 인과효과가 아니다. 희소한 카테고리 전환 경로는 확정 교차판매 정책이 아니라 메시지 가설로만 사용한다.

## 7. Page 04 — Model, CRM & Launch Gate

### 목적

모델의 대상 압축 능력, 발송 수용량의 손실, 실험 검정력과 실행 차단 조건을 한 화면에서 연결한다.

### 배치

```text
┌──────────────────────────────────────────────────────────┐
│ 평가범위 · 선택비율 · 가치구간 필터                     │
├───────────────────────────────┬──────────────────────────┤
│ 선택비율별 Lift·Recall        │ TP·FP·FN·Precision       │
├───────────────────────────────┼──────────────────────────┤
│ 표본크기·MDE 민감도           │ Launch Gate·Guardrail    │
├───────────────────────────────┴──────────────────────────┤
│ 결론: 후보 압축 ≠ 증분효과, 무작위 실험 필요            │
└──────────────────────────────────────────────────────────┘
```

### KPI와 Guardrail

| 구분 | 지표 |
|---|---|
| 모델 Primary | PR-AUC, Lift@k, Recall@k, Calibration |
| 수용량 | 선택 고객, Precision, FP, FN, 관찰 재구매자 1명당 접촉 |
| 실험 Primary | 24시간 초과 30일 재구매율의 ITT 차이 |
| 실험 Secondary | 60·90일 재구매, 주문가치, 공헌이익 |
| Guardrail | 수신거부, 불만, 취소, 반품, 발송 실패, 고객당 비용 |
| 실행 상태 | GO / ITERATE / STOP / NO DECISION |

### 필수 주석

모델이 포착한 과거 재구매자는 메시지 때문에 구매한 고객이 아니다. 캠페인 증분효과와 부작용은 향후 실험군·대조군 비교로만 검증할 수 있다.

## 9. 구현 완료 기준

- 4개 페이지의 카드·차트·표가 데이터 사전 정의와 일치한다.
- 공식 KPI와 운영 타깃이 시각적으로 분리된다.
- 모든 비율에 분모 또는 상세 툴팁이 제공된다.
- 외부 비교와 CRM 관찰값의 해석 제한이 항상 보인다.
- KPI 카드와 원천 CSV 값이 자동 대조된다.
- 필터 선택 시 빈 표본과 작은 표본이 숨겨지지 않는다.
- 대시보드 링크·대표 이미지·사용법이 최상위 README에 연결된다.
